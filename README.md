# ConsentMove

> Cloud data migration that runs on the user's own consent instead of a tenant-wide admin grant. The person moving their files authorises the transfer once through OAuth, the job runs under that delegated permission, and the audit trail shows who approved what — so IT never has to hold impersonation rights over every mailbox and drive to move one person's data.
